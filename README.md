The data is from https://github.com/thomas-haslwanter/statsintro_python/tree/master/ipynb/Data/amstat. \
The analysis includes two dataset (1) babyboom and (2) 93 cars. \
For (1) babyboom, \
The data describes the time and weights of the babies in December 21, 1997. \
The description of the data is in babyboom.txt. \
We use Babyboom_Dist.py to draw the distribution of the girls and boys. \

For (2) 93cars, \
The data describes the in formation of 93 cars in 1993. \
The description of the data is in 93cars.txt. \
We use Car_information.py to draw the distribution of the manufacturers and t-distribution of horsepower of cars.
